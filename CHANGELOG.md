# Changelog

All notable changes to Quickdraw are documented here.

## 1.0.0 - 2026-11-08

### Added

- Per-monitor resolution and refresh-rate switching from the Windows tray
- Named presets for multi-monitor display configurations
- Timed confirmation with automatic rollback
- Recovery after interrupted or unconfirmed display changes
- Optional launch at Windows sign-in
- Native Windows executable with embedded Quickdraw branding
